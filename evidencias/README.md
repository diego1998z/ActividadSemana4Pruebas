# Evidencias del laboratorio

Usar esta carpeta para guardar capturas, logs o enlaces relacionados con la ejecución del laboratorio.

## Evidencias recomendadas

1. Resultado local de `mvn test`.
2. Ejecución exitosa del workflow `CI` en GitHub Actions.
3. Fallo controlado del pipeline modificando temporalmente una aserción.
4. Ejecución corregida del pipeline después de revertir el fallo.

## Enlaces

- Workflow de GitHub Actions: agregar aquí el enlace cuando el repositorio esté publicado.
- Pull request: agregar aquí el enlace si la entrega se realiza mediante PR.

## Observaciones

No subir cambios con pruebas fallidas en la entrega final. El fallo controlado debe quedar documentado solo como evidencia.
